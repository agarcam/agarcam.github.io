# Personal Portfolio — Alba García Camacho

## About

Personal portfolio website showcasing my background, technical skills, and projects as a Computer Engineering student specializing in Computer Science, with a strong interest in Artificial Intelligence and software development.

The website highlights my academic experience, technical expertise, and personal projects across areas such as machine learning, computer vision, web development, and intelligent systems.

## Features

- **Personal Introduction:** Overview of my background, education, interests, and career goals.
- **Technical Skills:** A dedicated section showcasing the programming languages, tools, and technologies I work with.
- **Project Showcase:** A collection of academic and personal projects, including descriptions and links to individual project sections.
- **Contact Information:** Direct access to my email and professional profiles.
- **CV Download:** Downloadable copy of my curriculum vitae.
- **Code Highlighting:** Syntax-highlighted Python code snippet presenting my profile and technical interests.
- **Responsive Layout:** Viewport-aware structure designed for different screen sizes.

## Technologies

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layout, and visual design.
- **JavaScript** — Client-side functionality and syntax highlighting integration.
- **Prism.js** — Python syntax highlighting.
- **SVG** — Scalable icons for technologies and social media.

## Getting Started

No installation or build process is required.

1. Clone or download the repository.
2. Make sure the `images/`, `sites/`, and `files/` directories contain the required resources.
3. Open `index.html` in your browser.

For local development, you can also use the Live Server extension in Visual Studio Code.
